# Проверка внутридневных сигналов на фьючерсах Binance USD-M

Проверили 64 варианта на 12 контрактах. Десять вариантов дали плюс в одном из двух месяцев отбора. Ни один не закончил оба месяца с положительной доходностью счёта. Для независимого теста выбран разворот по ставке funding и отклонению от BTC при повышенном объёме и волатильности. Правило, порог, код и данные разработки зафиксированы до расчёта ноябрьского результата. В Telegram эта версия не включена.

В ноябре сделки появились в 10 из 24 дней по 7 контрактам. Три сделки достигли тейка, десять закрылись по стопу, две по времени. До издержек результат составил −69,63 USDT при стартовом счёте 10 000 USDT. Комиссии составили 48,74 USDT, спред 9,74 USDT, проскальзывание 19,48 USDT. Funding принёс 0,27 USDT. Итоговый счёт составил 9 852,68 USDT. Средний чистый результат сделки на выделенную маржу составил −1,57%.

## Как сравнивали варианты

- Модели обучались на мае–июле предсказывать чистый результат сделки LONG или SHORT с заданными уровнями выхода. В августе зафиксировали пороги по распределению оценок. В обучение или калибровку включали только примеры, весь двухчасовой горизонт которых завершился внутри соответствующего периода.
- Проверили регуляризованную линейную регрессию, градиентный бустинг, бустинг с объёмом агрессивных покупок и продаж, пробой, откат по тренду, отбой от экстремума, возврат к BTC, поглощение агрессивного потока, импульс потока и разворот по funding. Для части правил сравнили рыночный и заранее выставленный лимитный вход.
- Гипотезы добавлялись по результатам разработки на сентябре и октябре. При выборе сначала требовалось хотя бы 20 сделок в каждом месяце, затем сравнивалась доходность худшего месяца. Ноябрь оценивался только для одного выбранного варианта.
- Для финального правила LONG требует отрицательного последнего funding и отставания от BTC за 12 пятиминутных баров. SHORT требует положительного funding и опережения BTC. Оценка учитывает размер отклонения, ATR и относительный объём. Порог 2,103264 равен 99,9-му процентилю августовских оценок. Для активного режима относительный объём должен достигать 1,25, ATR — своей скользящей медианы. Процентиль не оценивает вероятность выигрыша.
- Решение каждые 15 минут по закрытой 5m свече, рыночный вход на следующем открытии. Выход по стопу, тейку или через два часа. Стоп равен максимуму из 0,45% цены и 1,6 ATR. Цель покрывает расходы и даёт плановые минимум 3% на маржу при 5× и минимум 1,25 размера чистого риска. Отношение 1,25 применялось только в этом эксперименте. При риске выше 5% маржи кандидат пропускается.
- Для лимитной заявки нужны пересечение цены минимум на 5 базисных пунктов и свободная маржа уже в момент выставления. Отмена через три свечи. При неоднозначном касании стоп имеет приоритет. На баре исполнения тейк засчитывался только при подтверждении ценой закрытия. По исполненной заявке списывали полные комиссии.
- Комиссия 0,05% на каждой стороне, спред 0,02% и проскальзывание 0,04% за круг, исторические ставки funding. Плечо 5×, риск 0,25% счёта на сделку, до четырёх позиций, до 10% маржи счёта на позицию. Номинал ограничен 1% оборота предыдущей свечи. Просадка измерена по закрытому результату. Очередь лимитных заявок, внутрисвечной путь и фактическая глубина стакана неизвестны.
- Набор из 12 заранее выбранных контрактов ограничивает переносимость на другие монеты. Пятнадцати закрытых сделок на независимом периоде мало для точной оценки винрейта.

Публичные свечи и доли агрессивных покупок взяты из биржевых архивов с проверкой SHA-256. Для ноябрьских платежей использована история funding Binance USD-M. [Описание данных Binance](https://github.com/binance/binance-public-data)

## Воспроизведение

Команды выполняются из корня проекта. Первый каталог содержит публичную выборку предыдущего аудита за май–октябрь вместе с исходными ZIP и манифестами. Результаты независимой проверки и CSV сделок записываются рядом с файлом отбора.

```text
python -m src.research.november_sample ../public_research_november
python -m src.research.strategy_challenge select --data ../public_research_2026 --report ../../outputs/challenge.json
python -m src.research.strategy_challenge holdout --data ../public_research_2026 --november ../public_research_november --report ../../outputs/challenge.json
python -m src.research.publish_challenge ../../outputs/challenge.json reports/signal-audit.json
```
